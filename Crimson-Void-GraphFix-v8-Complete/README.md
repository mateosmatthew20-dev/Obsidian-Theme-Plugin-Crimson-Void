# Crimson Void — Graph Performance Fix Bundle

Includes the existing Crimson Void Nova Theme v4 (unchanged) and the FX plugin v8 (updated).

Important: Graph Performance Guard temporarily suspends all FX while native Graph View is visible. This preserves the theme, red graph colors, and graph interactions while giving the native renderer priority.

Install by merging the `themes` and `plugins` directories into your vault `.obsidian` folder. Back up first; keep `plugins/crimson-void/data.json`. Reload Obsidian and check the Graph Performance Guard toggle is ON.
