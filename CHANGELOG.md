# Changelog

## Public Beta — Theme 4.0.0 + FX 8.0.0 (2026-10-31)

### Included
- Coordinated crimson-black Obsidian theme and separate FX plugin
- Animated eclipse, smoke, particles, notes, and empty tabs
- Dark sidebar, tabs, navigation, and status bar
- Native Graph View scarlet palette
- Graph Performance Guard that disables extra graph FX rendering to reduce interference with large graphs
- Motion and quality controls

### Known issues / caveats
- Some vaults contain extremely dense graphs; native Graph View can still be slow
- Native Obsidian compatibility on different operating systems and versions needs testing
- Visual appearance and app-window elements can vary with platform and Obsidian settings

### Before a directory submission
- Test install, update, disable, and uninstall in a clean vault
- Capture authentic screenshots on supported platforms
- Test with a representative large vault and record performance
- Review plugin API and security requirements

This release is distributed as source. No GitHub Release asset or official community directory submission is implied.
